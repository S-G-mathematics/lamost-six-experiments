## Shared data, roles, outcomes, and safeguards

The prepared LAMOST DR10 v2 baseline has 2,330,835 source representatives, seven labels (A, F, G, K, M, GALAXY, QSO), six numerical predictors (Pan-STARRS g/r/i/z/y and Gaia G), and a fixed 500,000-source test cohort. The remaining 1,830,835 sources form the development pool. IDs, counterpart IDs, spectral labels, signal-to-noise values, and audit fields are excluded as predictors. Correlated bands and valid extremes remain. The protocol specifies 80/10/10 allocation for fitting, tuning, and conformal calibration, with source/counterpart separation from test and saved role memberships. Learned preprocessing uses fitting rows only. (Sources: `benchmark/protocol_source.txt`, “Shared data and information boundaries”; `benchmark/Experiment_1_Setup_and_Readiness.txt`, “Data and predictors”.)

Primary predictive criterion is seven-class balanced accuracy; the second is mean split-conformal prediction-set size at a nominal 90% overall target. Report achieved overall and per-class coverage as diagnostics. The ordinary score is 1 minus class probability; SVMs without native probabilities use negative one-versus-rest margins. Threshold index is `ceil((m+1)*0.90)`, with infinity if it exceeds calibration count. No test-set threshold adjustment. Default paired bootstrap is 95%, 1,000 replicates; intervals condition on fitted models and thresholds and omit training/tuning/calibration variation. (Source: `benchmark/protocol_source.txt`, “Conformal evaluation and uncertainty”.)

## Experiment 1 — learning curves (frozen, running)

Question: which non-neural classifiers perform best as real-data budget grows, and where do generative/discriminative rankings change? The exact frozen design is nine budgets (100, 300, 1,000, 3,000, 10,000, 30,000, 100,000, 300,000, 1,000,000) × five paired repetitions × 17 methods = 765 cells. Methods: Gaussian NB, shared-diagonal Gaussian, shrinkage LDA, regularized QDA, GMM, Gaussian copula, ARF/FORDE density, multivariate KDE, continuous Chow–Liu, logistic regression, linear SVM, RBF SVM, kNN, CART, random forest, Extra Trees, histogram gradient boosting. Each budget has common paired memberships and nested development roles where feasible; samples are without replacement within a repetition; repetitions may overlap. Natural class proportions are retained subject to minimum support at small budgets. There is no augmentation, balancing, or corruption.

Each cell tunes by tuning balanced accuracy using seeded adaptive trials: ten trials for most methods and five for ARF, KDE, kNN, and RBF SVM. Duplicate proposals are cached; failures remain recorded and are not replaced by unlimited trials. Ties resolve by frozen simpler-first method-specific order, measured compute, then deterministic trial order. The one selected configuration is evaluated on the fixed test set; calibration is not used for selection. Report all run-level results, mean curves, paired differences, uncertainty, tuning choices, resources, and failures. Crossover claims are limited to observed sign changes between measured budgets.

Frozen master configuration: seed 271828; one worker; 180-second trial timeout; 6 GiB memory limit; prediction chunk 50,000; resource profile `native8gib8cores`; dependency lock `benchmark/dependencies.freeze.txt`. Verify config/source/dependency/protocol/baseline hashes before any continuation. The setup note separately describes its phase watchdog, RSS/AS controls, and 8 GiB host cgroup; do not conflate those safeguards. (Sources: `benchmark/results/master_run_config.json`, `benchmark/Experiment_1_Setup_and_Readiness.txt`, `benchmark/run_e1_sequential.py`, `benchmark/experiments.py`.)

## Experiment 2 — fidelity and classification (specified; not implemented as a runner)

Question: does a better statistical fit of a class-conditional generator correspond to better direct Bayes classification? Five flexible generators are primary (GMM, Gaussian copula, ARF/FORDE, KDE, Chow–Liu); four classical generative models are a separately labeled reference/sensitivity set. Use six development budgets 3,000, 10,000, 30,000, 100,000, 300,000, and 1,000,000 with five paired repetitions. Reuse valid selected E1 fits/trials; do not fit extra models solely for a fidelity ranking.

Per class, compare a generated diagnostic sample to held-out real observations using SDMetrics Quality Report over six features only; omit IDs and constant target. Average the seven class scores equally (explicitly a project class-balanced aggregation). The stated implementation default uses calibration-role observations as a non-adaptive reference only after model selection and conformal policy are frozen; diagnostic sample count per class is `min(2,000, available held-out class rows)`, shared across models. Fewer than two rows, zero-variance invalidity, or undefined report is unavailable; fewer than 20 rows is low precision. Pin SDMetrics version/metadata and retain marginal, pairwise, and column-pair details. Analyze Spearman correlation separately within budget/repetition across the five primary families; do not pool budgets. Within-family valid tuning configurations may be analyzed separately. Bootstrap diagnostics and saved test predictions jointly without retraining; preserve pairing. TSTR belongs to E3.

## Experiment 3 — three uses of each generator (specified; code path exists but execution unauthorized)

Question: for the same estimated distribution and real-data access, how do direct Bayes, synthetic-only learning, and real-only learning compare? Five generators: GMM, copula, ARF, KDE, Chow–Liu. One 100,000-row development budget and three paired repetitions (80,000 fit / 10,000 tune / 10,000 calibration). Reuse an exact matching E1 fit and freeze it. Generate exactly 5× the 80,000-row real fitting count (400,000), with deterministic label counts approximately matching empirical fitting proportions. All three downstream learners receive the same synthetic dataset within generator/repetition. Downstream learners are logistic regression, random forest, histogram gradient boosting, with equal trial budgets/domains across synthetic-only and real-only pairings. Real-only reference is shared across generators. There is no sample-size sweep and no real-plus-synthetic augmentation. Compare balanced accuracy and conformal set size on fixed test data; report all routes’ data access and separate fit/sampling/training/inference costs.

## Experiment 4 — class imbalance and restoration (specified; code path exists but execution unauthorized)

Question: how does reduced support for each class affect classification, and can generated restoration help compared with ordinary imbalance treatments? Three paired repetitions; implementation default 100,000 development rows with standard 80/10/10 roles. For each of seven classes, compare unchanged proportions, half the target’s original fitting share, and one-tenth that share. Estimate original share `p0` in that repetition’s unchanged fitting cohort and redistribute remaining rows proportionally among the other classes. Reserve tuning/calibration IDs before drawing fitting cohorts; use nested target-class subsets and shared other-class permutations. One unchanged control plus 14 altered conditions per repetition.

All 17 direct methods are compared on altered real cohorts. For logistic regression, random forest, and histogram gradient boosting, also compare untreated fitting, weighting toward original proportions, random oversampling, SMOTE, and target-class generated restoration from each of the five generators; the generator only sees the altered cohort. Restore to original target share, not equal class shares. Random oversampling, SMOTE, and generated restoration use the same added row count/final histogram. SMOTE uses an explicit multiclass count map and `min(5,n−1)` neighbors; fewer than two target rows is unsupported. Keep evaluation roles/test at population proportions and empirical-prior direct Bayes as main reference. No fixed-majority arm or factorial corruption crossing.

## Experiment 5 — corrupted fitting data (specified; code path exists but execution unauthorized)

Question: do generative/discriminative pipelines suppress, preserve, or amplify controlled corruption? Three separate sweeps (feature noise, missingness, label noise), with shared clean control and 5%, 10%, 20% affected fitting rows. Three paired repetitions; implementation default 100,000 development rows. Corrupt only the 80,000 fitting rows; tune/calibration/test are untouched. Reuse same base fitting sources, masks, and perturbation seeds across methods; masks are nested as rate rises.

Compare all 17 direct methods and the three E3 routes for each flexible generator with the three representative learners. Synthetic-only is 5× fitting count; no unrestricted augmentation. Mechanisms: (a) select affected rows uniformly; one of six features per row; add zero-mean Gaussian noise with SD equal to feature IQR/1.349 on permitted fitting data, falling back to standard deviation then a declared numerical floor; save altered cells/perturbations; (b) one randomly selected feature per affected row set missing (MCAR); fit median imputer on incomplete fitting data only; no missingness indicator; (c) independently select affected rows and relabel uniformly among the other six labels, so every selected label changes; retain transition tables and realized per-class rates. Freeze hyperparameters selected on matching clean fit/tune split, refit on corrupted data, and recalibrate on clean calibration data. No retuning in primary robustness analysis. These are defined mechanisms, not all possible measurement errors.

## Experiment 6 — generative ensembles (specified; no runner confirmed)

Question: do ensembles of five flexible generative classifiers improve classification or prediction-set efficiency? Implementation default 100,000-row development allocation and three paired repetitions, reusing exact matching clean E1 fits. Members: GMM, copula, ARF, KDE, Chow–Liu; same real fitting IDs and label order; each outputs normalized seven-class posterior probabilities. Average posteriors, not raw class densities. Compare equal weights (0.2 each) with one global learned nonnegative simplex vector per repetition, selected by tuning balanced accuracy on saved tuning posteriors only. Search default: equal vector, five vertices, 1,000 seeded Dirichlet(1,…,1) candidates, refine top ten by pairwise transfers of 0.10/0.05/0.01, cap 2,000 candidates. Ties choose closest to equal weights in Euclidean distance then deterministic order. Freeze before calibration. If any required member fails, five-member ensemble unavailable; any partial ensemble must be a labeled sensitivity result. Compare to every member and tuning-best member; no stacking, class-specific gating, or neural meta-learner.
